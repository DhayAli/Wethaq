# Wethaq (وثاق) Digital Detainee Transaction Management System

Overview : 
Wethaq is a specialized graduation project developed by Computer Science and Artificial Intelligence students at Umm Al-Qura University (Makkah). The system digitizes and automates detainee transaction management within the Public Prosecution, replacing traditional manual processes with an efficient, error-free automated web workflow to ensure secure handling and tracking of sensitive legal records.

Key Objectives & Features :
Automated Workflow & Transaction Management: Streamlines the creation and processing of detainee and case files across various centers (Police Stations, Prisons, Juvenile Homes, etc.).

Role-Based System Access: Manages distinct operational interfaces and permissions for three core user groups:

Observers (Public Prosecution): Monitor files, view historical records, and track status updates.

Center Staff: Create and submit new detainee files with auto-suggest ID features.

Prison Directors: Manage official court rulings and transmit update statuses.

Smart Search & Dynamic Views: Enables staff to perform quick searches, filter records by case or detainee status, and view organized center-specific files.

Automated Notifications & Updates: Triggers real-time alerts regarding status changes (e.g., case closures or scheduled release dates).
